欢迎使用 BilibiliDown 控制台

桌面端正在后台运行。下面提供了几个常用入口，可以在浏览器中直接访问相关功能。

解析与下载 输入视频 URL / av / BV，选择清晰度后加入下载队列。 任务列表 查看实时下载进度，暂停 / 继续 / 删除任务，下载已完成的文件。 设置 在线修改下载路径、命名格式、登录凭据等常用配置。 B 站账号 扫码登录、查看登录态、刷新 Cookie。 收藏夹下载 浏览自己的 B 站收藏夹，批量下载收藏视频（需登录 B 站账号）。 历史记录 查看下载历史与解析历史（需登录 B 站账号）。 极验验证 查看登录所需的人机验证页面（仅在桌面端触发登录后可用）。 刷新 Cookie 手动触发刷新登录凭据流程（同样需要桌面端配合）。 使用文档 查看官方使用指南、配置说明与常见问题。 项目主页 访问 GitHub 项目主页，查看源代码与版本更新。

提示：本控制台仅展示入口，下载、配置等操作请回到桌面端窗口完成。
